# Security Policy

## Supported Versions

| Version | Supported |
| --- | --- |
| 2.x | Yes |
| 1.x | No |

## Reporting a Vulnerability

Use GitHub private vulnerability reporting on this repository if it is enabled. Otherwise, open an issue that asks for a private contact channel and leave out exploit details.

## Scope

This is a local practice tool. Its web server is intended for loopback use and provides no TLS or authentication, so exposing it to a network is outside the supported use.
